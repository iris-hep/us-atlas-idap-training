# Visualization with mplhep

## Notebooks

* `hist_mplhep_text_book.ipynb` — the reference text. Ch. 0 setup, Ch. 1 `matplotlib`, Ch. 2 `mplhep`, Ch. 3 `hist`. Each chapter ends with a recap pointing at the matching problems.
* `hist_mplhep_problem_set.ipynb` — problems for each chapter plus a final exam.
* `hist_mplhep_problem_set_solutions.ipynb` — worked answers.

## Local environment with Pixi

If you would like to run parts of the module notebooks locally in a standalone environment, you can use the provided [Pixi](https://pixi.sh/) environment.

To do so:
* [Install Pixi](https://pixi.sh/latest/#installation)
* Run `pixi run start`
